This is a simple Java program that simulates rolling one or more dice. 
It prompts the user to enter the number of dice they want to roll, uses Java's Random class to generate a number between 1 and 6 for each die, 
and displays a fun visual representation of the dice faces using text characters, along with the total sum of all the rolls.

To run this program, ensure you have Java installed on your computer, open your terminal, and navigate to the folder containing the downloaded file.
You can compile the code by typing javac diceRoller.java and then execute it by typing java diceRoller. 
Follow the on-screen prompt to enter your desired number of dice and watch them roll!
